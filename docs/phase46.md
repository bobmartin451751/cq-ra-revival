# Phase 46 - procedural audio polish

## What changed
Added a small procedural audio layer with no imported sound assets:

- UI click
- move order acknowledgement
- attack order acknowledgement
- production/build completion
- combat explosion
- research/UI cue
- victory and defeat stingers

## Implementation
- `AudioDirector` synthesises short mono tones/noise bursts at scene start.
- One shared non-spatial AudioSource handles UI/orders/builds.
- Explosions use positional playback.
- The Audio object is generated by SceneBuilder, so no manual scene setup is needed.
- All calls fail silently when no director exists, keeping headless tests safe.

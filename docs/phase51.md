# Phase 51 - combat music layer

## What changed
Added a generated combat percussion layer separate from the ambient drone:

- 8-second looping low kick/tick pattern
- starts when a match begins
- stops on match end or when returning to the menu
- no imported audio assets

The ambient drone continues underneath both menu and battle.
